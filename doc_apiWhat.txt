Não é o frontend que chama.\n* **WebSocket** (`WS /ws`): o **frontend conecta** em ti (`ws://.../ws`) e recebe ao vivo `messages.upsert` e `connection.update`.\n\n### Fluxo receber (passo a passo)\n1. Mensagem chega no WhatsApp → Electrosoft faz `POST /webhook {event:\"messages.upsert\"}`.\n2. Backend guarda contacto + mensagem no SQLite.\n3. Backend envia via WS: `{\"event\":\"messages.upsert\",\"contato\":{...},\"mensagem\":{...}}`.\n4. Frontend mostra na lista.\n\n### Fluxo enviar (passo a passo)\n1. Frontend: `POST /api/enviar {numero, texto}`.\n2. Backend: Evolution `POST /message/sendText`.\n3. WhatsApp recebe.\n\n## Exemplo frontend (JS)\n\n```js\nconst ws = new WebSocket(\"ws://localhost:8000/ws\");\nws.onmessage = (e) =\u003E {\n  const d = JSON.parse(e.data);\n  if (d.event === \"messages.upsert\") atualizarLista(d.contato, d.mensagem);\n};\n```\n\n## Endpoints base\n\n* `GET /` — estado + `ligadosWS`\n* `POST /webhook` — só a Electrosoft chama (não testar no browser)\n* `WS /ws` — frontend conecta aqui (não aparece nos testes HTTP)\n* `POST /api/enviar`, `POST /api/enviar-media`\n* `GET|POST|PUT|DELETE /api/contatos`, `GET /api/conversas`\n* `GET /api/mensagens/recebidas`, `GET /api/mensagens` (Evolution)\n",
